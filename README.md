# ObjectiveQuestion

English question gallery and human-review pages for *From Open-Ended Tasks to Multi-Format Objective Questions: A Knowledge-Guided Design Framework*.

- Review: https://zhangzhengchen.github.io/ObjectiveQuestion/
- Questions: https://zhangzhengchen.github.io/ObjectiveQuestion/questions.html
- Criteria and aggregation: https://zhangzhengchen.github.io/ObjectiveQuestion/guide.html

This upload contains only the question/review pages and necessary browser functionality. Research generation code, API logs, model ratings, manuscripts and private course materials are not included.

Four experts rate three aspects: Target Alignment, Answer and Scoring Validity, and Question Design Quality. Work is stored in the reviewer’s browser; completed JSON files must be downloaded and returned to the coordinator. There is no central submission service. Human scores have not yet been collected.

Literature materials derive from *Approaching prose fiction*, Steve Padley / The Open University, first published 2012, updated 2018, used/reworked under CC BY-NC-SA 4.0. Practice passages are researcher-written. See the page footers for attribution. These are research examples, not official Open University questions. TreeQuestion-style and ConQuer-adapted outputs are identified as adaptations; no upstream source code is redistributed.

GitHub Pages source: main branch, repository root. No build dependencies are needed.

Supplementary examples: https://zhangzhengchen.github.io/ObjectiveQuestion/other-subjects.html

The supplementary page contains three complete additional sets: 10 assessment focuses and 10 questions per source (30 questions total). It has no rating form and publishes no model or expert quality results. It is separate from the main review dataset. Adapted content retains per-source attribution and CC BY-SA 4.0 or CC BY-NC-SA 4.0 terms as indicated on the page; third-party source material is excluded.
