Worked example: reviewing an AI-drafted public notice

Expert reviewQuestions · 30 itemsScalability examplesWorked method exampleRating guide

This AI-literacy example requires no programming background. A student society plans to publish a food-drive webpage. The assessment target is to judge separate review decisions using evidence and intended public use.

The same case runs through all five stages below: a reviewed target; a contextual open recommendation task; decomposition of knowledge, case facts and operations; selective simplification; and four independent warranted/not-warranted judgments. Independent memo writing and an overall release decision are not retained.

Reviewer context, not part of the student question

Evaluating AI outputs against evidence and intended use

Before use, evaluate relevance, accuracy, clarity, completeness, confidentiality, compliance, bias and sources. Select the checks relevant to the actual intended use.

Retained judgment: Judge four proposed review decisions independently for whether each action and rationale is warranted by the public intended use, supplied evidence, and relevant output-review considerations.

Source: Videos 5.1 and 7.1 ·

A society will publicly post an AI-drafted food-drive page tomorrow. The date is confirmed, the collection point is unconfirmed, recipients are called “the needy,” a citation cannot be found, and a volunteer’s private phone number appears without stated authorization. Mark each proposal warranted or not warranted. An authoritative source is one responsible for event information.

p1Verify the collection point with an authoritative source; confirming only the date could still leave donors with an incorrect location.
p2Replace “the needy” with neutral wording because the public description may represent recipients in a biased or inappropriate way.
p3Verify the citation or remove it because readers should not be directed to a source that cannot be found.
p4Keep the private phone number because publicizing a direct contact is relevant to helping donors reach the society quickly.

Whole-item exact match; no partial credit.

Reference answer and explanation

p1: Supported; p2: Supported; p3: Supported; p4: Not supported

P1 is warranted: the location remains unconfirmed, and checking the date alone is insufficient. P2 appropriately addresses potentially biased public wording. P3 addresses source reliability. P4 is not warranted because relevance does not resolve the confidentiality risk; without stated authorization, the private number should be removed or replaced with an authorized public contact.

Five-stage design record

Stage 1: assessment target and observable evidence

Evaluate several independently warranted output-review decisions using evidence, intended use and relevant evaluation criteria.

Parallel judgments about what to verify or revise and why, including plausible but insufficient checks. Do not bundle all actions into one best overall plan.

Stage 2: scenario and open task

You are helping a student society publish an AI-drafted webpage for a campus food-drive. The draft gives the correct event date but names an unconfirmed collection point, omits wheelchair-access information, describes recipients as “the needy,” cites a source that cannot be found, and includes a volunteer’s private phone number. The page is intended for public use tomorrow.

Write a concise release recommendation to the society editor. For each issue, state whether to verify, revise, remove, or accept it; identify the relevant review consideration; and justify your decision using the intended public use and the stated evidence. Include at least one check that would be insufficient on its own.

GRASPS

Goal: Make defensible, evidence-guided decisions about an AI draft before publication.

Role: Student communications reviewer

Audience: Society editor

Situation: A public webpage must be reviewed before release.

Product: A concise release recommendation with separate decisions for each issue.

Success criteria

  • Addresses every stated issue separately.
  • Selects review considerations relevant to public use.
  • Links each action to case evidence.
  • Identifies why one plausible check is insufficient alone.

Stage 5: response design

A four-proposition true/false matrix preserves the parallel-judgment relation while respecting the response limit. Coverage is explicitly narrowed by removing the wheelchair-access issue rather than combining it with another issue.

Performance not retained

  • Independent production of an editor recommendation.
  • Generating original actions, review considerations, and rationales.
  • Forming a conditional overall release recommendation.
  • Reviewing the omitted wheelchair-access information.
  • Demonstrating completeness review through the wheelchair-access issue.
  • Addressing every issue from the original case.
