Relationships among AI, generative AI, chatbots and prompts

Generative AI creates new content; a chatbot provides a natural-language interface; a prompt is an input guiding the system. Distinguish the roles of capability, interface and instruction.

Retained judgment: Evaluate the correspondence between four concrete service components and the distinct roles of classification, content generation, conversational interface, and guiding input, while avoiding confusion between the interface and the system producing content.

Source: Video 1.1 ·

A university help service labels requests as admissions, fees, or housing and drafts replies shown in a conversational window. A student types, “Reply politely in under 80 words and include the housing-office email.” Classification means assigning an item to an existing category. Match each component to its best role. Use each option once. The service’s technical architecture is unspecified.

Choices

C1Chooses among predefined outcomes; it does not compose the response.
C2Produces the response wording rather than merely sorting the request.
C3Supports the natural-language exchange; what powers it is unspecified.
C4Directs the desired output through user-supplied requirements.

Rows to match

R1Applying one of the three request labels
R2Writing a reply not previously supplied
R3The window where messages are exchanged
R4The student’s sentence about tone, length, and required information

Whole-item exact match; no partial credit. Use each option at most once.

R1 → C1 (Chooses among predefined outcomes; it does not compose the response.); R2 → C2 (Produces the response wording rather than merely sorting the request.); R3 → C3 (Supports the natural-language exchange; what powers it is unspecified.); R4 → C4 (Directs the desired output through user-supplied requirements.)

Structured prompt design with TACOS

TACOS specifies Task, Audience, Context, Output and Sources. Evaluate how these requirements work together for the intended use rather than counting labels.

Retained judgment: Select the prompt revision and accompanying rationale that most coherently support the intended orientation use while respecting the source boundary and acknowledging a genuine remaining limitation.

Source: Video 3.1 ·

Improve “Write something about campus services for students.” Select the most coherent revision and rationale for a new-student orientation note. It must cover service locations from the supplied campus-map text and library times from the supplied notice, using both texts and no other sources. A usable format is readily consultable; a meaningful limitation is a practical trade-off or boundary.

AWrite a detailed staff report using both texts and general university knowledge. Detail supports completeness, but students may find it long.
BUsing both supplied texts only, create a concise new-student orientation note with headings for service locations and library times. Headings aid consultation, but brevity may omit detail.
CUsing only the library-hours notice, create a new-student checklist of opening times. It is quick to use but omits service locations.
DUsing both supplied texts only, write an academic essay for new students about service locations and library times. Evidence is bounded, but the essay is slow to consult.

Whole-item exact match; no partial credit.

Reference answer and explanation

B (Using both supplied texts only, create a concise new-student orientation note with headings for service locations and library times. Headings aid consultation, but brevity may omit detail.)

B integrates the intended task, new-student audience, orientation setting, consultable format, and both permitted sources. Its rationale connects headings to usability and identifies a genuine brevity–detail trade-off. A changes the audience and allows outside knowledge. C excludes the map and its location information. D respects the audience and source boundary but deliberately selects a format poorly suited to ready consultation.

C2Prediction

Rows to match

p1Verify the collection point with an authoritative source; confirming only the date could still leave donors with an incorrect location.
p2Replace “the needy” with neutral wording because the public description may represent recipients in a biased or inappropriate way.
