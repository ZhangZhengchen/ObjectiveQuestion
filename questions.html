AI01 · Matching

Course outcome / target: Explain the relationships among AI, generative AI, chatbots and prompts, and distinguish their roles in practical AI use.

Sampled assessment focus: Distinguish changes to the chatbot interface, the prompt, and the underlying generative AI model in a practical content-generation task.

Teaching video source documents · Teacher-confirmed learning outcome; generated item-level focus.

A university office uses a chat application to draft event announcements. Staff type a request, and a server-based system produces a new draft. For each independent change below, identify the component directly changed. All other components remain fixed. Choose one answer per row; choices may be used more than once.

A Chatbot interface
B Prompt
C Underlying generative AI model
R1 Staff replace “Write a formal announcement” with “Write a friendly announcement under 100 words.”
R2 The office replaces the chat window with a redesigned conversation screen that sends the same requests.
R3 The provider replaces the server's text-generation engine while retaining the conversation screen and staff requests.

Whole-item exact match; no partial credit. Options may be reused.

Reference answer and explanation

R1 → B; R2 → A; R3 → C

R1 → B: Changing the requested tone and length changes the input instructions, not the interface or processing model. R2 → A: Replacing the conversation screen changes the interaction interface; the requests and model remain fixed. R3 → C: Replacing the engine that generates text changes the underlying model, not the screen or input instructions.

AI02 · Multiple select

Course outcome / target: Use TACOS to organise and revise prompts for a stated purpose and context, aligning task, audience, context, output and source requirements.

Sampled assessment focus: Identify local audience and source revisions that align a prompt with a stated brief without changing its already-aligned task, context, or output requirements.

Teaching video source documents · Teacher-confirmed learning outcome; generated item-level focus.

A university library needs recommendations for supervisors addressing students’ difficulty finding books. The recommendations must use only the attached student survey and appear in a two-column table: problem and proposed action. Draft prompt: “Recommend improvements for a university library where students struggle to find books. Write for student visitors. Use a two-column table: problem and proposed action. Draw on the attached survey and library websites.” Which TWO edits align the prompt with the brief while preserving requirements already met?

A Replace “student visitors” with “library supervisors.”
B Replace the source instruction with “Use only the attached student survey.”
C Replace the table instruction with “Write a short briefing for library supervisors.”
D Replace “Recommend improvements” with “Summarise students’ reported difficulties.”

Whole-item exact match; no partial credit.

Reference answer and explanation

A, B

A corrects the audience: students experience the problem, but supervisors will read the recommendations. B corrects the sources by excluding websites, as the brief requires. C names the right audience but replaces an already-correct output format. D substitutes summarisation for recommending improvements, changing the required task rather than repairing a mismatch.

AI03 · Multiple select

Course outcome / target: Analyse required processing and results in learning or work tasks, choose suitable AI capabilities, and judge when a combination of capabilities is needed.

Sampled assessment focus: Distinguish assigning existing text to established categories from composing new text, and recognize that a task requiring both outputs needs classification and generation capabilities.

Teaching video source documents · Teacher-confirmed learning outcome; generated item-level focus.

A university library has 300 written student comments and three established categories: opening hours, study spaces, and borrowing services. Staff want each comment assigned to a category and a newly written paragraph describing the main concerns in each category. They do not need estimates of future usage or suggestions for services to offer. Which AI capabilities are needed in combination to produce these outputs? Select TWO. Treat capabilities as functions, even if one tool provides both.

A Classification
B Prediction
C Generation
D Recommendation

Whole-item exact match; no partial credit.

Reference answer and explanation

A, C

A is correct because assigning comments to established categories requires classification. C is correct because composing paragraphs from the categorized comments requires generation. B is incorrect because the requested outputs describe existing feedback rather than estimate future usage. D is incorrect because staff are not requesting suggested services or actions. The two required functions may be supplied by one tool; combining capabilities does not necessarily mean using multiple tools.

AI04 · Multiple select

Course outcome / target: Analyse subtasks, input-output handoffs, capability choices, validation and human responsibility in an AI-supported workflow, judging whether they support the overall task goal.

Sampled assessment focus: Identify when generation and validation lack the upstream evidence they require, and select local handoff repairs without replacing the workflow or transferring human accountability.

Teaching video source documents · Teacher-confirmed learning outcome; generated item-level focus.

A university wants accurate answers to orientation questions. Staff select current official sources and remain responsible for release. Retrieval produces relevant passages; classification assigns an office label. The drafting tool receives only the question and office label. A staff reviewer receives only the draft and checks its clarity before release. Which TWO changes repair the information handoffs needed for factual accuracy while retaining these subtasks and staff responsibility?

A Pass the retrieved official passages to the drafting tool alongside its existing inputs.
B Give the reviewer the official passages and require comparison with the draft.
C Pass the office label to the reviewer as the factual reference for checking the draft.
D Have staff check the retrieved passages instead of checking the generated draft.

Whole-item exact match; no partial credit.

Reference answer and explanation

A, B

A supplies the factual input needed for grounded drafting. B supplies evidence for human validation of the actual draft. C confuses a routing output with evidence supporting factual claims. D checks an upstream output but leaves the generated response unvalidated; accurate retrieved passages do not establish that the draft represents them accurately.

AI05 · Multiple select

Course outcome / target: Analyse how an agent adapts plans to tool results and user feedback, and judge whether tool actions satisfy information, authorisation and human-validation conditions.

Sampled assessment focus: Determine when new feedback requires further evidence gathering and human review, while distinguishing calendar access from approval of a specific calendar action.

Teaching video source documents · Teacher-confirmed learning outcome; generated item-level focus.

A student asks an agent to find official university presentation support and propose a personal practice event, requiring approval before calendar changes. The student checks evidence for a paid workshop, then says, “I now need a free resource I can use alone.” A new search result mentions a self-study checklist, but its page has not been opened. The calendar is connected; the proposed Tuesday 4:00–4:30 pm event remains unanswered. Which TWO next actions satisfy the student's updated requirements and workflow conditions?

A Open the checklist page, check access and suitability, and present evidence for student review before revising the guide.
B Revise the guide from the search result, carrying forward the student's earlier evidence approval.
C Keep the calendar unchanged and request explicit approval of the proposed event's exact date and time.
D Create the proposed event provisionally through the connected calendar, then ask the student to verify its details.

Whole-item exact match; no partial credit.

Reference answer and explanation

A, C

A is correct: the new requirement changes what evidence is needed; the checklist's access and suitability must be checked and its evidence reviewed before revision. B is incorrect: approval of the workshop evidence does not validate evidence for a different resource. C is correct: a connected calendar provides access, not approval, and silence does not authorise the proposed action. D is incorrect: describing an event as provisional does not remove the requirement for approval before a calendar change; later verification cannot replace prior permission.

AI06 · Matching

Course outcome / target: Evaluate AI-output quality and use risks against task purpose, verifiable evidence and output-evaluation criteria, choosing appropriate checking, revision or safeguards.

Sampled assessment focus: Distinguish relevance, clarity and completeness problems in AI-generated guidance, and select a targeted revision without treating one quality criterion as a substitute for another.

Teaching video source documents · Teacher-confirmed learning outcome; generated item-level focus.

A university needs a guide showing new students how to submit travel-expense claims. It must cover receipts, submission steps and deadlines. Match each draft review finding to the most appropriate targeted revision. Preserve content already checked as correct. Use each option at most once; one option is unused.

A Improve completeness: add the missing required information.
B Improve accuracy: replace incorrect claims using current university policy.
C Improve relevance: redirect the content toward the requested practical task.
D Improve clarity: explain unfamiliar terms in student-friendly language.
R1 The draft accurately describes the history of university travel funding, but gives no claim instructions.
R2 All required information matches policy, but unexplained administrative terminology makes instructions difficult for new students.
R3 Receipt requirements and submission steps are correct and understandable; the required deadline is absent.

Whole-item exact match; no partial credit. Options may be used at most once.

Reference answer and explanation

R1 → C; R2 → D; R3 → A

R1–C: Accurate background does not serve the requested instructional purpose; the draft needs redirection, not just an additional detail. R2–D: The information is complete and policy-checked, so explaining terminology addresses the audience's difficulty without changing verified facts. R3–A: The draft addresses the task but omits a required element, so adding the deadline addresses completeness. B is unused: no finding identifies an incorrect factual claim, and an absent fact is not the same as a false one.

TEAM01 · Single choice

Course outcome / target: Distinguish a change to meeting topics from a change to how participants examine and discuss those topics; select a process adjustment suited to the stated meeting need.

Sampled assessment focus: Select a change to meeting process, rather than topics, that fits the different engagement needs of agenda items and the participation pattern.

OpenLearn BG012_1, PDF pages 8, 9, 10 · Source-grounded author draft; not yet individually confirmed by an instructor.

A team meeting must cover routine progress reports and a disputed scheduling proposal. Reports need only factual clarification; the proposal needs examination from several perspectives. The same two members usually dominate discussion. Which revision best addresses these needs?

A Replace individual progress reports with a combined report and split the scheduling proposal into smaller agenda topics, retaining the usual discussion approach.
B Keep both topics, allow clarification after reports, and agree ground rules for examining the proposal that give each member space to contribute.
C Keep both topics and agree that every item receives a full dialogue, with each member contributing before the team moves on.
D Keep both topics, allow clarification after reports, and let the two most vocal members debate the proposal before others ask questions.

Whole-item exact match; no partial credit.

Reference answer and explanation

B

B adjusts how participants engage, matching clarification to reports and wider examination to the proposal while addressing dominant voices. A changes the organisation of content but retains the problematic meeting style. C changes the process but assumes every item needs full dialogue, despite the reports needing only clarification. D distinguishes the agenda items but preserves dominance and gives other members only a questioning role rather than space to contribute perspectives.

TEAM02 · Matching

Course outcome / target: Distinguish a standing structure that prevents destructive conflict from its use to support people in a current conflict; recognise that one arrangement can serve both functions.

Sampled assessment focus: Distinguish the preventative function of establishing an open team routine from the curative function of using it to support colleagues in an existing conflict, and recognise that the arrangement can serve both functions.

OpenLearn BG012_1, PDF pages 11, 12, 13 · Source-grounded author draft; not yet individually confirmed by an instructor.

A team introduces a weekly review where staff can discuss mistakes without blame. The manager intends this routine to build openness and reduce damaging disputes. Later, two colleagues whose disagreement has stalled a handover use a review to explain their concerns; teammates help them restart dialogue. Classify each aspect below by its conflict-management function. Choose one category per row. Categories may be used more than once.

A Preventative only
B Curative only
C Both preventative and curative
R1 Establishing the routine to build openness and reduce damaging disputes.
R2 Helping the two colleagues restart dialogue about their stalled handover.
R3 The review arrangement, considering both its establishment and its use here.

Whole-item exact match; no partial credit. Options may be reused.

Reference answer and explanation

R1 → A; R2 → B; R3 → C

R1–A: Establishing a routine that encourages openness is preventative; this aspect does not itself describe support for a particular current conflict. R2–B: Helping colleagues through their existing disagreement is curative; this aspect concerns the current intervention rather than establishing the standing structure. R3–C: The arrangement serves both functions through its establishment and subsequent use. Treating the whole arrangement as exclusively preventative or curative overlooks one of those functions.

TEAM03 · Single choice

Course outcome / target: Choose a proportionate managerial response to the described development of conflict, distinguishing monitored self-resolution from abandonment and adapting intervention as circumstances change.

Sampled assessment focus: Recognise when monitored self-resolution should shift to facilitated communication, rather than continuing an ineffective approach, withdrawing oversight, or imposing an unnecessarily visible resolution.

OpenLearn BG012_1, PDF pages 13 · Source-grounded author draft; not yet individually confirmed by an instructor.

Two colleagues disagree about dividing project work. Both initially ask to settle it themselves, so their manager agrees and checks progress privately. A week later, they have stopped discussing the division and each is waiting for the other to restart. Work is beginning to slip, but both remain willing to talk privately. Which response is most proportionate now?

A Keep the existing private progress checks, leaving the colleagues to decide when to restart discussions.
B Arrange a private conversation to help them restart discussions, then check whether their agreement restores progress.
C Announce a manager-decided division at the next team meeting, then check whether both colleagues follow it.
D Suspend progress checks to give them space, asking them to report back when they have settled the division.

Whole-item exact match; no partial credit.

Reference answer and explanation

B

B adapts the approach as the conflict develops: communication has stalled, so private facilitation with follow-up is proportionate. A retains monitoring but does not address the newly stalled communication. C imposes a visible managerial solution despite both colleagues remaining willing to talk privately. D mistakes supporting self-resolution for withdrawing oversight while work is slipping. The source supports monitored self-resolution, facilitation of communication, and changing the approach as circumstances develop (BG012_p13).

TEAM04 · Single choice

Course outcome / target: Distinguish reciprocal concessions from a jointly developed solution addressing both parties concerns, without assuming compromise is always wrong or collaboration always feasible.

Sampled assessment focus: Distinguish a time-constrained reciprocal concession from a jointly developed solution addressing both parties’ concerns, while recognising that the initial compromise can be defensible.

OpenLearn BG012_1, PDF pages 14, 15, 21 · Source-grounded author draft; not yet individually confirmed by an instructor.

A support team must set tomorrow’s rota in ten minutes. Jo wants continuous phone coverage; Ren wants uninterrupted time for complex cases. With no time to test alternatives, each accepts less of their preferred allocation so the rota can be issued. Next week, they have time to examine the problem together. They challenge their assumptions and jointly develop rotating phone duty with protected casework periods, meeting both concerns. Which interpretation is best supported?

A Both agreements are collaboration: each results from the two people accepting a shared arrangement.
B The first is defensible compromise; the second is collaboration through joint examination and development.
C Both agreements are compromise: rotating duties still means dividing time between competing activities.
D The first is failed collaboration; they should delay the rota until both concerns can be met.

Whole-item exact match; no partial credit.

Reference answer and explanation

B

B is correct: the immediate agreement involves reciprocal concessions under a stated deadline, whereas the later solution is jointly developed through dialogue and addresses both concerns. A confuses agreement alone with collaboration. C treats dividing time as sufficient evidence of compromise, overlooking how the later solution was developed and what it achieves. D assumes compromise is unacceptable and disregards the requirement to issue the rota. The course allows compromise to be useful while encouraging exploration of collaborative solutions (BG012_p14–15, BG012_p21).

B The presenters’ assignments fit the idea advocate role.

TEAM06 · Ordering

Course outcome / target: Determine the necessary dependencies between articulating a plan assumptions, constructing a counter-plan using counter-assumptions, examining both, and developing shared tested assumptions for a new plan.

Sampled assessment focus: Determine the dependency chain from making a plan’s assumptions explicit, through developing and examining a counter-plan grounded in counter-assumptions, to establishing shared, scrutinised assumptions for a new plan.

OpenLearn BG012_1, PDF pages 16, 17 · Source-grounded author draft; not yet individually confirmed by an instructor.

A library team is using dialectical inquiry to plan evening opening hours. Put these four work packages in the order required by the method, from first to last. Each package is completed once.

A Present both plans and their supporting evidence to the review group; probe weaknesses and identify overlooked assumptions.
B Jointly pool and scrutinise assumptions, reconcile or test competing ones where possible, and use agreed core assumptions to develop a new plan.
C Develop an evening-opening proposal and give its key underlying assumptions to the counter-proposal group.
D Develop an alternative plan by finding plausible counter-assumptions and using them to uncover or reinterpret evidence.

Whole-item exact match; no partial credit.

Reference answer and explanation

C → D → A → B

C precedes D because the counter-proposal group works from the original plan’s explicit assumptions. D precedes A because both plans and their supporting assumptions must be available for examination. A precedes B because the joint work draws on assumptions exposed and challenged during the debate. B culminates in agreed core assumptions that support a new plan; it is not simply a choice between the original plans. The source permits reconciliation or testing where possible, rather than requiring an empirical test of every assumption.
