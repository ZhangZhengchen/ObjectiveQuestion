Concept-Relation-Guided Objective Question Authoring

Generating Better Objective Questions for an Introductory AI Course: A Concept-Relation-Guided LLM Authoring Approach.

Current approach

Start from a small set of related course concepts. Make the relationship explicit, instantiate a scenario, approve a bounded assessment focus, and construct an objective item whose response structure exposes the intended judgment.

Course content → Related concepts → Concept relation → Scenario → Assessment focus → Objective item

Evidence status

The revised three-condition study is planned, not executed: ten AI-course themes, one output per theme and condition, thirty items. Expert results are pending.
